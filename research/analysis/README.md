# Analysis notes

This folder is meant for notebooks and analytical summaries that compare route choices against urban conditions.

Planned outputs:
- route choice heatmaps;
- comfort vs speed trade-off charts;
- time-of-day analysis;
- route-frequency comparison;
- value of comfort-aware routing against baseline shortest-path routing.

The final objective is to test whether users benefit from comfort-aware navigation in practice, not only in theory.
