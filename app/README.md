# Bishkek Comfort Map App

This folder contains the API layer and future web interface for the project.

Current MVP:
- FastAPI service with `/` and `/routes` endpoints
- demo route generation for a sample Bishkek corridor
- route alternatives with comfort explanations

Next planned work:
- Map UI with Leaflet/MapLibre
- dynamic time/date controls
- route recalculation by weighted priorities
- GIS data integration
